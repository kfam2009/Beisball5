Stream Deck - Baseball5 NDI Scorebug

Usar en Stream Deck:

1. Elegir la accion: Sistema > Abrir.
2. En "App / Archivo", seleccionar uno de estos archivos .vbs.
3. El panel/NDI debe estar levantado con scripts\START_NDI_SCOREBUG.cmd.

Acciones principales:

SCOREBUG_IN.vbs
SCOREBUG_OUT.vbs
AWAY_PLUS.vbs
AWAY_MINUS.vbs
HOME_PLUS.vbs
HOME_MINUS.vbs
OUT_PLUS.vbs
OUT_MINUS.vbs
OUTS_CLEAR.vbs
BASE_1.vbs
BASE_2.vbs
BASE_3.vbs
BASES_CLEAR.vbs
INNING_PLUS.vbs
INNING_MINUS.vbs
SET_PLUS.vbs
SET_MINUS.vbs
HALF_TOGGLE.vbs

Si Stream Deck no muestra los .vbs o .lnk, usar los .exe dentro de:

shortcuts-exe

Iconos iniciales para botones:

icons\AWAY_PLUS.png
icons\AWAY_MINUS.png
icons\HOME_PLUS.png
icons\HOME_MINUS.png
icons\OUT_PLUS.png

icons\BASE_1.png
